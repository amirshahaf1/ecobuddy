# EcoBuddy — גרסת ה"אמיתי"

זו הגרסה השנייה של הפרוטוטיפ: אפליקציית ווב אמיתית עם **GPS אמיתי**, **מצלמה אמיתית לסריקת QR**, ו**מפה חיה** עם נתוני מיקומי מחזור אמיתיים מהעירייה. היא בנויה כאתר סטטי טהור (HTML/CSS/JS, בלי שרת, בלי בנייה) — קל להריץ, קל לפרוס.

## מה אמיתי כאן ומה לא (חשוב לדעת)

**אמיתי:**
- **מיקום (GPS):** `navigator.geolocation` אמיתי — המרחק לפח מחושב מהמיקום שלך בפועל.
- **מצלמה + סריקת QR:** `getUserMedia` + הספרייה `jsQR` קוראות QR חי מהמצלמה, לא סימולציה.
- **נתוני מיקומי מחזור:** נשלפים בזמן אמת מה-API הפתוח של עיריית תל אביב-יפו (ArcGIS REST, שכבה 787 "מתקני מחזור"), מסונן לסוגים שקשורים לפח הכתום (אריזות פלסטיק/מתכת/קרטוני משקה). זה **מקור נתונים אמיתי וציבורי**, לא נתוני דמו.
- **אימות מרחק בזמן סריקה:** סריקת QR מאושרת רק אם אתה בפועל בטווח של עד 80 מטר מהפח שנסרק (ניתן לשינוי בקוד: `PROXIMITY_M` ב-`app.js`).
- **EcoBuddy AI (אופציונלי):** אם תדביק מפתח Anthropic API אישי בעמוד הפרופיל, הצ'אט קורא ל-API האמיתי (`api.anthropic.com`) ומקבל תשובות AI אמיתיות, מותאמות לפי הטאב שהכי ביקרת בו. בלי מפתח — חוזר להודעות מוכנות מראש.

**עדיין לא אמיתי (מודע ומתועד):**
- **אין שרת / מסד נתונים** — כל הנתונים (נקודות, רצף, לוח מובילים) נשמרים רק בדפדפן שלך (`localStorage`). אם תנקה נתוני גלישה או תעבור למכשיר אחר, זה יתאפס.
- **לוח המובילים מדומה** — "החברים" הם נתונים קבועים בקוד, לא משתמשים אמיתיים.
- **אין QR רשמי על פחים אמיתיים** — לעירייה/תמיר אין תוכנית QR כרגע. בעמוד הפרופיל יש כלי "הפק מדבקה" שיוצר QR אישי (`ecobuddy:<מזהה הפח>`) שאתה יכול להדפיס ולהדביק בעצמך ליד פח אמיתי, לצורך פיילוט אישי — זה לא קוד רשמי של אף גורם.
- **מכסה רק תל אביב-יפו** — זה המקור הפתוח היחיד שמצאתי. פח מחוץ לאזור? אפשר להוסיף אותו ידנית בעמוד הפרופיל (כולל "השתמש במיקום הנוכחי שלי").

## איך מריצים מקומית

צריך שרת מקומי פשוט (לא ניתן לפתוח את הקובץ ישירות מה-Explorer/Finder כי המצלמה והמיקום דורשים "הקשר מאובטח"):

```bash
cd ecobuddy-app
python3 -m http.server 8000
```

ואז לפתוח בדפדפן: `http://localhost:8000`

זה יעבוד למחשב עם מצלמה, אבל **לבדיקה בנייד** צריך HTTPS אמיתי (ראו למטה) — נייד לא סומך על `localhost` של מחשב אחר.

## איך מריצים בנייד (עם HTTPS אמיתי) — מומלץ: GitHub Pages, בחינם

1. פתחו חשבון GitHub (אם אין) ויצרו ריפו חדש, למשל `ecobuddy`.
2. העלו את כל התוכן של התיקייה `ecobuddy-app/` (index.html, styles.css, app.js, manifest.json) לריפו.
3. ב-Settings → Pages, בחרו את הענף (branch) הראשי כמקור, ושמרו.
4. אחרי דקה-שתיים תקבלו כתובת כמו `https://<username>.github.io/ecobuddy/` — זו כתובת HTTPS אמיתית.
5. פתחו את הכתובת בדפדפן בנייד, אשרו הרשאות מיקום ומצלמה כשמתבקש, ואפשר גם "הוסף למסך הבית" כדי שזה יתנהג כמו אפליקציה.

חלופות מהירות לבדיקה זריזה בלי לפרוס: `ngrok http 8000` או Cloudflare Tunnel מעל השרת המקומי — נותנים כתובת HTTPS זמנית שמצביעה למחשב שלכם.

```
  manifest.json  — מאפשר "הוסף למסך הבית" בנייד
```

## מקור הנתונים (מיקומי פחים)

עיריית תל אביב-יפו, שכבת GIS ציבורית "מתקני מחזור" (ID 787), נגישה ללא צורך במפתח:
`https://gisn.tel-aviv.gov.il/arcgis/rest/services/IView2/MapServer/787`

השאילתה באפליקציה מסננת לפי השדה `t_sug` (סוג המתקן) לרשימה מדויקת של סוגי פחי אריזות/כתומים (`TAU_PACKAGING_TYPES` ב-`app.js`) — אלו הפחים המקבילים ל"פח הכתום" השכונתי. **חשוב:** משתמשים ב-`IN (...)` ולא ב-`LIKE ... OR LIKE` — חומת האש של העירייה חוסמת את התבנית הזו והבקשה נכשלת בדפדפן (נראית כשגיאת CORS). שדות רלוונטיים נוספים בשכבה: `shem_rechov` (רחוב), `ms_bait` (מספר בית), `ms_mechalim` (מספר מיכלים).

## מה הצעד הבא (כשתרצה)

- **שרת + מסד נתונים אמיתי** (למשל Supabase/Firebase) כדי שהנקודות, הרצף והלוח מובילים יהיו משותפים בין מכשירים/משתמשים אמיתיים.
- **הרחבה מעבר לתל אביב** — בדיקה אם לעיריות נוספות (שרובן משתמשות באותה פלטפורמת GIS) יש שכבה דומה, ואיחוד כמה מקורות.
- **שיתוף פעולה עם תמיר/עירייה** לקבלת QR רשמי על פחים אמיתיים, במקום מדבקות אישיות.
- אם תרצה שהצ'אט של EcoBuddy יעבוד עם AI בלי שכל משתמש יזין מפתח משלו, יידרש שרת קטן (proxy) שמחזיק את המפתח בצד השרת — זה גם הצעד הראשון לקראת "אפליקציה מלאה" עם backend.
